## FiveMinute

Сайт для проведения "пятиминуток" — небольших тестов от преподавателей предметов МатМеха для проверки знаний студентов.
Проект в первую очередь нацелен на удобство для преподавателей: разграничение тестов и шаблонов, ограничение по времени,
возможность запланированного открытия и закрытия теста.

Не забыли и о студентах — для них реализована автоматическая отправка ответов по истечении времени, а также добавлены 
различные цитаты из цитатника ФИИТ.

Стек технологий: ASP.NET Core, EF Core, PostgreSQL, Docker.
